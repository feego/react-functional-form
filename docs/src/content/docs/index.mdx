## Describe the form once, get the types for free

Declare the value types on the fields, or let a Standard Schema provide them. Values, `onSubmit`,
field props and nested forms are all typed from the schema.

```ts
const schema = createForm({
  email: createField(z.string().email()),
  age: createField<number>(),
  tags: createList(createField<string>()),
})

const form = useController({ schema, onSubmit: (values) => api.save(values) })
//                                               ^? { email: string; age: number; tags: string[] }

form.setFieldValue('age', '42') // ❌ Type error: age is a number
```

[How typing works →](/react-functional-form/guides/typescript/)

## Build a sub-form once, use it anywhere

A nested form is a complete form component with its own schema. Its state lives in the parent, and its
events bubble up.

```tsx
function AddressForm({ propsForForm }: { propsForForm: ControllerProps<typeof addressSchema> }) {
  const form = useController(propsForForm)
  const getPropsForField = useGetPropsForField(form)
  return <TextInput label="City" {...getPropsForField('city')} />
}

const schema = createForm({ billing: addressSchema, shipping: addressSchema })

<AddressForm propsForForm={getPropsForNestedForm('billing')} />
<AddressForm propsForForm={getPropsForNestedForm('shipping')} />
```

## Validate your way

Chain built-in validators, write your own (sync or async), or use Zod, Valibot or ArkType. No adapters
needed.

```ts
const isAvailable = createValidator(async (username: string) =>
  (await api.isTaken(username)) ? 'Username taken' : undefined,
)

const schema = createForm({
  username: createField<string>([requiredValidator, isAvailable]),
  email: createField(z.string().email()),
  password: createField<string>([requiredValidator, createMinLengthValidator(8)]),
})
```

## Form state is plain React state

Values, touched and errors are ordinary `[state, setState]` pairs. The controller creates them for you,
or you can pass your own: lift them to a parent, share them, or persist them.

```ts
// Any [state, setState] pair works, e.g. one backed by localStorage.
const valuesStateHook = useLocalStorageState('draft', { title: '', body: '' })

const form = useController({ schema, valuesStateHook }) // the draft survives page reloads
```

[Controlled & lifted state →](/react-functional-form/guides/lifted-state/)

## Schemas are data

Schemas are plain values, so they can depend on the form's own values.

```ts
const buildSchema = (method?: 'email' | 'phone') =>
  createForm({
    method: createField<'email' | 'phone'>([requiredValidator]),
    email: method === 'phone' ? undefined : createField<string>([requiredValidator]),
    phone: method === 'phone' ? createField<string>([requiredValidator]) : undefined,
  })

const formState = useFormState({ schema: buildSchema() })
const [values] = formState.valuesStateHook
const form = useController({ ...formState, schema: buildSchema(values?.method) })
```

[Schemas →](/react-functional-form/guides/schemas/)

## Lists with stable keys

Add, remove and reorder items. Touched and error state follow each item, and so does its React key.

```tsx
const members = useController(getPropsForNestedForm('members'))
const { items, getPropsForItem, append, remove, move } = useFieldArray(members)

items.map(({ key, index }) => (
  <MemberForm key={key} propsForForm={getPropsForItem(index)} onRemove={() => remove(index)} />
))
```

[Field arrays →](/react-functional-form/guides/field-arrays/)

## Everything else a form needs

Submit state, dirty tracking, server errors, validation modes, focus on error, and native inputs.

```tsx
const form = useController({ schema, mode: 'onChange', shouldFocusError: true, onSubmit })

<input {...getPropsForInput('email')} />
<button disabled={!form.isDirty || form.submitState.isSubmitting}>Save</button>
<button type="button" onClick={() => form.reset()}>Discard changes</button>

form.setErrors({ email: 'Already registered' }) // e.g. from the server response
```
